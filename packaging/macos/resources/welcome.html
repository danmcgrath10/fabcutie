FabCutie is an open-source parametric EQ.

The next steps let you pick where to install and which formats. Logic Pro and GarageBand use the Audio Unit.

Install for all users (needs an administrator password) puts the plug-ins in /Library/Audio/Plug-Ins and the app in /Applications. Install for me only uses ~/Library/Audio/Plug-Ins and ~/Applications instead. To pick between them, click Change Install Location... on the Installation Type step.

Any FabCutie already in your own Plug-Ins folders is replaced, so your DAW only sees this version. If you switch from "all users" to "me only", delete the copies in /Library/Audio/Plug-Ins yourself.

If Logic Pro is open, quit and reopen it after installing.
